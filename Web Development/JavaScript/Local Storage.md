#javascript
É uma variável usada para salvar configurações dentro da sessão de um usuário.
Um exemplo de uso é salvar o modo escuro que um usuário selecionou anteriormente, na próxima vez que o usuário entrar no site o modo escuro continuará ligado.

Vale lembrar que se o usuário desligar o `localstorage` do navegador ele vai parar de funcionar.
