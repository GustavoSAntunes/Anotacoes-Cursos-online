#html

Podemos criar ids e classes:
Para criar ids, escreva [id=]"(nome do id)" dentro de uma tag.

Para criar classes, do mesmo jeito que anteriormente, escreva [.] e o nome da classe e aperte enter. Desse jeito a classe será criada e então será vinculada ao lugar que se encontra.

Podemos criar uma div juntamente com a sua classe ao escrevermos: 
``div.container``

com o exemplo acima, teremos a saída:
``<div class="container"> </div>``


E, seguindo o exemplo acima, depois de criarmos um container iremos querer criar os seus ``items``.
Para isso, podemos usar:
``div.item*x``

Onde ``x`` é a quantidade de divs com a classe ``item`` desejados.
