`<h1>` -> Exemplo de título`</h1>`
	`<h1>`: Abertura de tag.
	Exemplo de título: Conteúdo.
	`</h1>`: Fechadura de tag.


`<p>` -> Exemplo de Parágrafo `</p>`


`<div>` ->Tag usada para agrupar blocos de elementos e aplicar CSS neles.

## Formatação de texto

`hr` -> Insere uma linha horizontal.

`br` -> Quebra de linha. (também funciona com imagens)

<!-- --> -> Comentários.

`em` -> indica ênfase (itálico)

`strong` -> Indica forte importância

`i` -> faz um texto ficar em italico (sem semântica)

`b` -> faz um texto ficar em negrito (sem semântica)

`mark` -> Faz um texto ficar destacado, por referência ou por atenção extra.

`abbr` -> abreviação

`var` -> representa variável em matemática

`sub` e `ins` -> Normalmente são usados juntos, o primeiro indica que algo foi deletado e o segundo indica que foi inserido, exemplo: Eu gosto de `del` vermelho `/del` (deletado) `ins` azul `/ins` (inserido, substituição).

`details` e `summary` -> Usados em conjunto, o `details` é usado para oferecer informações adicionais ao usuário, e o `summary` é a legenda ou sumário desse conteúdo.
```details
<details class="descricao">
	<summary>Saiba mais...</summary>
	<p>Conteúdo</p>
</details>
```

## Outros

`&lt;` e `&gt;` -> Less Than (<) e Greater Than (>).
Eles são usados pois os símbolos `<` e `>` são reservados para as tags.

`lorem` -> tag usada para criar um texto qualquer, útil para testes.
