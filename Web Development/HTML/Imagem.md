#html #imagens 

```
<img src="foto.png" alt="Exemplo de foto">

<img: Abertura de tag.

src= : Parâmetro.

"Exemplo de foto": Valor 
```

PS: em source (src), pode-se usar CTRL + SPACE para procurar a imagem que deseja.
`<img src="foto.png" alt ="Exemplo de foto">`

`src=` -> Arquivo da foto, use o atalho CTRL + SPACE para localizar com mais facilidade a imagem que deseja

**PS:** Coloque as imagens em uma pasta dedicada a elas, faça a mesma coisa com o arquivo de estilo. Ao localizar a imagem no CSS, use `../` para "voltar" uma pasta e encontrar o que deseja.

Exemplo de estilização de imagem em CSS:

```
display: block;

margin: auto;

width: 200px;

aspect-ratio: 1/1;
```
