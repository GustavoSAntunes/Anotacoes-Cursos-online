#html

Para inserir ícones, primeiro precisamos importá-los do [Google Fonts](https://fonts.google.com)

Pesquisar os ícones desejados e copiar seus links e colar no header do HTML

Exemplo de ícones:

```
<link rel="stylesheet" href="https://fonts.googleapis.com/css2?family=Material+Symbols+Outlined:FILL@0..1&icon_names=mail,person,vpn_key&display=block">
```

No exemplo acima, foi possível por mais de um ícone com a mesma configuração

**PS: SÓ É POSSÍVEL POR ATÉ 2 ÍCONES EM UMA MESMA CONFIGURAÇÃO, ACIMA DISSO ELA IRÁ FALHAR.**

Exemplo:
```
<link rel="stylesheet" href="https://fonts.googleapis.com/css2?family=Material+Symbols+Outlined:FILL@0..1&icon_names=mail,person,vpn_key&display=block">

<link rel="stylesheet" href="https://fonts.googleapis.com/css2?family=Material+Symbols+Outlined:FILL@0..1&icon_names=mail&display=block">
```

# Font-awesome

A segunda opção é usarmos o [Font Awesome](https://fontawesome.com/)

Primeiro, entre no link de [kits](https://fontawesome.com/kits) com a conta logada,
Add new Kit,
Escolher o Free Styles,
Escolher o nome e imagem do kit,
Em Set Up, copiar e colar o link do kit em seu site.

Depois de configurado, podemos escolher qualquer ícone grátis no [site](https://fontawesome.com/icons)

Para mais informações em como estilizar os ícones, use o [W3C](https://www.w3schools.com/icons/fontawesome5_intro.asp)
